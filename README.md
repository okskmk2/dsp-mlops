# DS Platform

내부 MLOps 관제 웹입니다. Azure ML·Azure Databricks의 학습 UI를 복제하지 않고, 신청·결재·프로비저닝·모니터·승격·재학습 요청·감사를 담당합니다.

시각 언어는 `docs/design-system.json`, 기능·권한·라우팅은 `docs/dsp-web-spec.json`을 단일 소스로 구현했습니다.

## 실행

```sh
pnpm install
pnpm dev
```

브라우저에서 http://localhost:5173 을 엽니다. 1920px 너비를 기준으로 설계되어 있으며, 그 미만에서는 가로 스크롤을 유지합니다.

## 데모 계정

로그인 화면에서 플랫폼 역할을 고릅니다.

| 계정 | 역할 | 볼 수 있는 범위 |
| --- | --- | --- |
| 김관리 | 관리자 | 전 프로젝트, 프로비저닝 재시도, 설정 |
| 이직책 | 직책자 · 승인권자 | 전 프로젝트 읽기 |
| 박오너 | 일반 · 프로젝트오너 | 소속 프로젝트 쓰기 |
| 최코디 | 일반 · 코디네이터 | 멤버·기준치·승격 상신 |
| 정개발 | 일반 · 프로젝트원 | 재학습·오염 선언 |
| 한뷰어 | 일반 · 뷰어 | 읽기 전용 |
| 강결재 | 승인권자 | 품의 승인/반려 |

데이터는 세션 메모리입니다. 테마와 로그인 계정만 `localStorage`에 남습니다.

## 스택

Vue 3, Vite, Pinia, Vue Router, `@lucide/vue`
